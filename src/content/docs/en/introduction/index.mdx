FitTrack is a **mobile-first workout tracker** you build end to end: one **Python/FastAPI** backend on **Supabase** (managed Postgres + Auth), a **Flutter** mobile app, and a **Svelte** web companion — two clients sharing a single JWT-secured API.

This introduction sets the scene before you write any code:

- [Overview](/fittrack/en/introduction/overview/) — what FitTrack is, the feature list, and the map from each module to the Learn Hub course it adapts.
- [Architecture](/fittrack/en/introduction/architecture/) — how FastAPI, Supabase, and the two clients fit together, and why the responsibilities are split the way they are.
- [Prerequisites](/fittrack/en/introduction/prerequisites/) — the tools to install before Module 1.
- [Roadmap](/fittrack/en/introduction/roadmap/) — where FitTrack sits in the six-project Real-World Projects series.
