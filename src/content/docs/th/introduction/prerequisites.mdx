## สิ่งที่ต้องติดตั้ง

คุณไม่ต้องมีครบทุกอย่างตั้งแต่วันแรก — แต่ละ tool จะถูกแนะนำใน module ที่ใช้ครั้งแรก — แต่นี่คือ list เต็มเผื่อคุณอยากติดตั้งไว้ล่วงหน้า

- **Python 3.12+** และ **[uv](https://docs.astral.sh/uv/)** — package และ project manager ของ Python ที่เร็วซึ่ง backend ใช้ `uv` จัดการ virtualenv, dependency และการรันแอป
- **[Supabase CLI](https://supabase.com/docs/guides/cli)** — สำหรับรัน Supabase stack แบบ local และจัดการ migration พร้อม **บัญชี Supabase** ฟรีสำหรับโปรเจกต์ที่ hosted
- **Docker** — Supabase stack แบบ local รันใน Docker และ Module 13 จะ containerize FastAPI backend
- **[Flutter](https://docs.flutter.dev/get-started/install) 3.x** — สำหรับแอป mobile (Module 9–10) พร้อม iOS Simulator หรือ Android emulator
- **Node.js 20+** — สำหรับ Svelte web companion (Module 11)
- **REST client** — `curl`, [HTTPie](https://httpie.io/) หรือ REST tool ใน editor ของคุณ ไว้ยิง API ก่อนที่ client จะมีอยู่

## คอร์สนี้ถือว่าคุณรู้อะไรมาแล้ว

FitTrack เป็นโปรเจกต์ระดับ intermediate คุณจะได้ประโยชน์สูงสุดถ้าคุณคุ้นกับ:

- **Python เบื้องต้น** — function, class, `async`/`await` ไม่ต้องเชี่ยวชาญลึก; module ของ FastAPI อธิบาย pattern ไปพร้อมกัน และอิงกับ *Python for TypeScript Developers* ตรงที่การเทียบช่วยให้เข้าใจ
- **HTTP และ REST** — method, status code, JSON request/response
- **SQL เบื้องต้น** — table, join และ aggregation ง่าย ๆ Module 8 ลงลึกกว่านี้
- **frontend บ้าง** — คุณไม่ต้องเคย Flutter หรือ Svelte มาก่อน; ทั้งคู่สอนตั้งแต่ setup ถ้าคุ้นกับ component framework ตัวไหนก็ช่วยได้

## ตรวจสอบผล

คุณ setup พร้อมแล้วเมื่อ:

- `python --version` ขึ้น 3.12 หรือใหม่กว่า และ `uv --version` ใช้ได้
- `supabase --version` ใช้ได้ และ `docker` รันอยู่
- `flutter doctor` รายงานว่าไม่มีปัญหาที่ block
- `node --version` ขึ้น 20 หรือใหม่กว่า

ต่อไป [roadmap](/fittrack/th/introduction/roadmap/) จะแสดงว่า FitTrack อยู่ตรงไหนใน series ที่ใหญ่กว่า
