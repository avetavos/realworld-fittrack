FitTrack คือ **แอปบันทึกการออกกำลังกายแบบ mobile-first** ที่คุณสร้างเองตั้งแต่ต้นจนจบ: backend หนึ่งตัวเขียนด้วย **Python/FastAPI** บน **Supabase** (managed Postgres + Auth), แอป mobile บน **Flutter** และ web companion บน **Svelte** — สอง client แชร์ API เดียวที่ป้องกันด้วย JWT

introduction นี้ปูภาพให้ก่อนที่คุณจะเขียนโค้ดสักบรรทัด:

- [Overview](/fittrack/th/introduction/overview/) — FitTrack คืออะไร, มี feature อะไรบ้าง และแต่ละ module map ไปยังคอร์สใน Learn Hub ตัวไหนที่ดัดแปลงมา
- [Architecture](/fittrack/th/introduction/architecture/) — FastAPI, Supabase และสอง client ต่อกันยังไง และทำไมความรับผิดชอบถึงถูกแบ่งแบบนี้
- [Prerequisites](/fittrack/th/introduction/prerequisites/) — tool ที่ต้องติดตั้งก่อนเริ่ม Module 1
- [Roadmap](/fittrack/th/introduction/roadmap/) — FitTrack อยู่ตรงไหนใน Real-World Projects series ที่มีหกโปรเจกต์
